# Snap Implementation of SAXR

This project implements the visualization of the Situated Analytics in eXtended Reality ([SAXR](https://link.springer.com/chapter/10.1007/978-3-032-33500-5_3)) specification using the [Snap's AR platform](https://developers.snap.com/) with [Lens Studio](https://developers.snap.com/lens-studio/home) and [Camera Kit](https://developers.snap.com/camera-kit/home).
The implementation of the data processing, as well as the documentation of the syntax can be found on the [SAXR GitHub](https://github.com/metason/SAXR).

## Project Structure
- [LensStudio](LensStudio/): Lens Studio project of the SAXR Lens, [README](LensStudio/README.md)
- [CameraKit](CameraKit/): Web app (Vite + TypeScript) that runs the SAXR Lens in the browser using Camera Kit, [README](CameraKit/README.md)
