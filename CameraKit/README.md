# Camera Kit

This Camera Kit project provides a web application to display the SAXR lens.
Currently, this app showcases how to set a URL as an input to a Lens using launch parameters.

> [!WARNING]
> WIP: This code is not tested for different browsers, nor is it ready for a production deployment.

## Setup
Install dependencies:
   ```bash
   npm install
   ```

## Run
```bash
npm run dev
```
Then open the URL shown in the terminal.

To view it on a mobile device:

In VS Code: Forward the port, visibility: private
Open a new incognito window in the browser, sign in with the same GitHub Account as signed in VS Code.


## Update Camera Kit
```bash
npm install @snap/camera-kit@latest
```
